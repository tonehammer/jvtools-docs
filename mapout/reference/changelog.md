# Changelog

## Version 1.0
<p style="font-size:0.75rem; font-weight:400; opacity:0.38; letter-spacing:0.02em; margin:-0.85rem 0 1.2rem;">28 October 2026</p>

The first public release.

**Mapping**

* Perspective corner pin with a calibration grid, edited on the projector.
* Mesh warp for surfaces that are not flat.
* Rotation about a pinned corner or the image centre.
* Mapping files: save and load the mapping as JSON.

**Shapes**

* Rectangles, ellipses and Bezier polygons drawn and edited on the projection.
* Snapping, box and lasso selection, rename, duplicate and undo from the projector.
* Masks, by shape or by group.

**COP network**

* Sync Shapes to COPs: a row per shape, with its own UV.
* Perspective-correct UV on four-corner faces, a draggable UV frame on the rest.
* UV check, group layers with mask, ID and SDF, and shapes as geometry.

**Output**

* Fullscreen projector window, always on top, following the playbar.
* Multi-projector regions with edge blending.
* Blackout, test pattern, flips, exposure and gamma trim.
